Evidence

Everything the product claims, with the measurement behind it and the assumption that limits it. Thresholds were registered and hashed before any data was collected. Where one moved afterwards, the amendment says so.

What we measured about the API

Six differential tests. Each one asks whether the response changes when a parameter is removed, because this API answers 200 to parameters it does not understand. Two of the six did not resolve, and are here with that verdict rather than left out.

The location matrix

The finding the product is built on, and the one most worth checking. Two spellings, two modes, measured the same way.

A row that changes nothing in either column is a parameter the API accepted and did not apply. signal.location and filter.location return no results at all: those spellings are not real. The product uses none of them: it describes an audience by the entities it already loves, which is what the rest of this page measures.

What the agent does without Qloo

The same question, put to a language model that sees only the two title lists. There is no ground truth for what a programmer would license, so this measures divergence, never correctness.

Why the set, and not the rank correlation

Two reasons. First, rank correlation at this n has a wide null distribution. The standard error is nearly as large as the value, so a single tau looks far more precise than it is. Second, it is computed from the model's full ordering, and that ordering is not reliably reproducible between recordings. The set of five has been identical in every run we have recorded. So the set is the primary measure, and the correlation is reported as a range with its error.

How the hero pair was chosen

Every candidate evaluated, with the reason each did or did not qualify, is published in HERO_SWEEP.md. The rule was hashed before the data existed. The amendment that enlarged the candidate audiences records what had been seen at the time and states that no criterion, threshold, tie-break or model setting changed.

Honest limits

  • Qloo knows brands, not products. This works for films, artists, places, books, shows, podcasts and games, but not arbitrary retail SKUs.
  • 15 of the 18 map audiences have too few members to split into halves that can disagree, and are drawn dashed rather than implying a check that did not happen.
  • The two readings of any audience are disjoint, not independent. They share no entities but both come out of the same graph, so their agreement is a consistency check rather than corroboration.
  • Divergence from a language model is not evidence that the model is wrong. There is no ground truth here.
  • Every number on this site is a snapshot of the graph in October 2026.
