What we measured about the API

Every parameter was differential-tested — assert the response changes when the parameter is removed — because this API silently ignores what it does not understand, which makes an untested parameter indistinguishable from a working one.

filter.location.query is ignored for movies Pin a candidate set and vary the city across New York, São Paulo, Tokyo, Mumbai and Berlin: affinities come back identical to four decimals. It is honoured for places. Any entry that pins a set and varies location is reading a parameter the API never applied. reproduce: python3 run_all.py — tests F0 and F
affinity and popularity sit side by side They are different numbers in the same response. Popularity is identical in every market, so a client that reads it makes every audience look alike. Ranking here uses query.affinity with no fallback. reproduce: python3 probe_api.py
Affinity is not normalised per candidate set The same entity scored inside two different pinned sets, with the same signal, returns the same value. It varies with the signal, not the set — so rank positions from one pinned query are comparable by construction. reproduce: python3 run_all.py — tests B (normalisation) and C (filter.results.entities)

What the agent does without Qloo

The same question, put to a language model that sees only the two title lists. There is no ground truth for what a programmer would license, so this measures divergence, never correctness.

Why the set, and not the rank correlation

Two reasons. First, rank correlation at this n has a wide null distribution — the standard error is nearly as large as the value — so a single tau looks far more precise than it is. Second, it is computed from the model's full ordering, and that ordering is not reliably reproducible between recordings. The set of five has been identical in every run we have recorded. So the set is the primary measure, and the correlation is reported as a range with its error.

We also chose which films count as regionally skewed and which anchors represent each home, so the selection is ours, and the eleven cases are not fully independent because films sharing an audience move together.

Every hero-sweep qualifier fell below the separation floor The 0.35 floor was in the code from 17 October, nine days before the sweep was registered. All four qualifying pairs sit under it. We label that on the page rather than hide it, and the floor was not recalibrated afterwards to make any pair look better.

How the hero pair was chosen

Every candidate evaluated, with the reason each did or did not qualify, is published in HERO_SWEEP.md. The rule was hashed before the data existed; the amendment that enlarged the candidate audiences records what had been seen at the time and states that no criterion, threshold, tie-break or model setting changed.

Honest limits

  • Qloo knows brands, not products. This works for films, artists, places, books, shows, podcasts and games — not arbitrary retail SKUs.
  • 15 of the 18 map audiences have too few members to split into halves that can disagree, and are drawn dashed rather than implying a check that did not happen.
  • The two readings of any audience are disjoint, not independent. They share no entities but both come out of the same graph, so their agreement is a consistency check rather than corroboration.
  • Divergence from a language model is not evidence that the model is wrong. There is no ground truth here.
  • Every number on this site is a snapshot of the graph in October 2026.
